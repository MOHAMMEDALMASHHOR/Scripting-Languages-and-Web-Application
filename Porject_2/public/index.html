📚 Weekly Learning Overview

W1 / E1 – Introduction

  • Overview of scripting languages and how they work on both client and server side.
  • JavaScript basics, console usage, and REPL in Node.js

W2 / E2 – Introduction to NoSQL Databases

  • Learned about the structure and differences of NoSQL vs SQL
  • Basic understanding of collections, documents, and MongoDB structure

W3 / E3 – Creating NoSQL Databases

  • Creating MongoDB collections and inserting documents
  • Hands-on with basic `insertOne()` and `insertMany()` operations

W4 / E4 – Querying and Modifying Data

  • Querying using `find()` with filters
  • Updating documents using `updateOne()`, `updateMany()`, `deleteOne()`, `deleteMany()`

W5 / E5 – Simple PHP Web Apps

  • Created basic PHP forms, GET/POST handling
  • Validated inputs and stored sessions

W6 / E6 – OOP in PHP

  • Class creation, object instantiation, public/private properties, `__construct` method
  • Using `this` and understanding encapsulation

W7 / E7 – PHP & Data Access

  • Connecting PHP with MongoDB (NoSQL)
  • Read and write operations through PHP scripts

W8 / E8 – PHP Frameworks

  • Explored Laravel-like patterns and controller-views separation
  • Routing and simplified CRUD operations

W9 / E9 – Intro to Node.js

  • Installed Node.js using nvm (or OneCompiler)
  • Ran scripts with `node`, created web server with `http` module

W10 / E10 – Web Apps with Node.js

  • Used Express.js to define routes `/`, `/about`, `/contact`
  • Served static files and used modules like `os`, `path`, and `events`

This project summarizes all lessons into one Node.js web app with routing and static content.
